🩺 MedVerse AI

AI-powered medical education Telegram bot for students worldwide.

Features

- AI Medical Tutor
- Multilingual support (7 languages)
- Medical education and explanations
- Anatomy and Histology
- Pharmacology and Microbiology
- Medical Dictionary
- Educational Clinical Cases
- AI Study Notes
- Medical Tests
- PowerPoint presentations
- PDF documents

Technologies

- Python 3.11+
- Aiogram 3
- Google Gemini AI
- SQLite
- Python-PPTX
- ReportLab

Installation

Install dependencies:

pip install -r requirements.txt

Configure environment variables:

BOT_TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_gemini_api_key

Start the bot:

python bot.py

Important

MedVerse AI is designed for medical education. It does not replace professional medical advice or diagnosis.
